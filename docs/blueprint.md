# **App Name**: Gomezgani Shaba Portfolio

## Core Features:

- Project Showcase: Present selected projects with clear problem statements, system architecture, technology stack, screenshots, and key lessons learned.
- Skills Overview: Structured presentation of technical skills grouped by languages, frameworks, data & machine learning, security, and development tools.
- About Section: A concise professional summary introducing Gomezgani Shaba as a full-stack developer and data science student focused on building secure, data-driven systems.
- Contact & Outreach: A simple contact form enabling visitors to directly reach Gomezgani Shaba for collaboration, opportunities, or inquiries.

## Style Guidelines:

- Primary Color: Deep blue (`#34495E`) to convey professionalism, stability, and trust.
- Background Color: Light gray (`#F0F3F4`) for a clean, modern, and low-contrast reading experience.
- Accent Color: Teal (`#008080`) for highlighting interactive elements and calls to action.
- Headline Font: *Space Grotesk* (sans-serif) for a modern, technical tone.
- Body Font: *Inter* (sans-serif) for clarity, readability, and consistency across devices.
- Design Approach: Minimalist layout with a strong information hierarchy, prioritizing clarity, usability, and content over decoration.
- Motion & Feedback: Subtle, purposeful animations to provide interaction feedback without distracting from content.
